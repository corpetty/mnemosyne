## Mnemosyne 0.19.0

### One task across meetings
- **A task that comes up again is the same task.** When a later meeting lists an action item an earlier meeting already had open, the two become one task: same wording always, close wording when the meetings are related (the same recurring meeting or the same people). Each link is in the meeting's history and one click undoes it. A task you already ticked that comes up again starts as a new open one.
- **Tick it once.** Ticking a task, following it or giving it an issue link, in Tasks, in a meeting, in Obsidian or through MCP, applies to every meeting that mentions it.
- **Tasks shows each task once.** A row says "in N meetings" and lists what each meeting said, with **Unlink** per meeting. **Link to an earlier task** joins two by hand, and **Suggested links** lists close matches in the meetings you already have, to accept or dismiss.
- **Summaries show the thread.** An action item says "↩ continues from <meeting>", a decision "supersedes …" when a later meeting changed it (link them with **Supersedes…**) or "also decided in …" when it was decided again. The decisions log in Obsidian shows what superseded what.
- **One checkbox per task in Obsidian.** Only the newest meeting's note has the checkbox; earlier notes say "↩ continued in [[later note]]", so vault-wide task queries list a task once. Settings → Obsidian → **Export all meetings again** updates the notes you already have.
- The pre-meeting brief, people, organizations and the MCP tools list a task once; an issue created for a task covers every meeting that mentions it.
- On first start, identical open tasks in the meetings you already have are joined (close matches only appear as suggestions).
- Settings → Obsidian: **Link tasks across meetings** (same or close wording, same wording only, or off) and **Let the summary model link tasks too** (off by default: the model is shown open tasks from related meetings; never with the built-in model, and never tasks from local-only meetings to a cloud model).

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
