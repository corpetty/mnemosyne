## Mnemosyne 0.26.0

### Noise suppression
- **A clean mic for your calls.** With echo cancellation on, press **Enable** next to **Noise suppression**. Mnemosyne downloads DeepFilterNet (53 MB, once) and adds **Mnemosyne: mic (clean)**, which takes keyboard, fan and room noise out of your echo-cancelled mic. Pick it as the microphone in your call app.
- **Two strengths.** **Remove noise** takes out as much as it can. **Turn noise down** only lowers it.
- **Your recordings stay as transcribable as before.** Mnemosyne records the mic before noise suppression, because in our tests the denoised audio transcribed worse in noisy rooms. To record the denoised audio anyway, tick **Record it denoised too**.
- **A busy computer doesn't cut you off.** If the noise suppressor can't keep up and stops, recordings carry on, and the clean mic switches to your echo-cancelled mic without the noise removal. The row tells you when this happens.
- It uses no CPU while nothing listens to the clean mic. It runs on x86_64 Linux only for now.

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
