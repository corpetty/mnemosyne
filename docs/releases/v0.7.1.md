## Mnemosyne 0.7.1

### Fixes
- **The app could freeze while recording.** The live transcript ran its speech recognizer on every CPU core every few seconds, which starved the window (and the rest of the desktop) until the app had to be restarted. It now uses two cores (Settings file: `live_threads`), which is also faster, and it skips stretches where nobody is talking instead of transcribing silence.
- The recording screen no longer animates continuously (pulsing dots, animated level meters), which kept the window busy while recording.
- The "torchcodec is not installed correctly" warning in the logs is gone. It was harmless: Mnemosyne never uses that decoder.

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download it below and verify with `sha256sum -c SHA256SUMS`.
