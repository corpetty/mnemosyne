## Mnemosyne 0.5.0

### New
- **Automatic updates**: the app checks for a new release shortly after it starts (and from Settings → Updates) and offers "Update and restart". Updates are signed; the AppImage replaces itself, and deb and rpm installs ask for your password. This is the first release that can update itself, so installing 0.5.0 by hand is the last manual upgrade.
- **Level meters and a capture self-test**: live input levels for each source while recording, a "check" button for every input, and "test capture" for outputs, which plays a short tone and confirms that system audio is really being recorded (not your microphone).
- **Transcription progress**: each stage (transcribing, identifying speakers) is named, with a progress bar and time remaining, in the transcript view and the session list.
- **Names and terms (glossary)**: list names and jargon, plus `wrong -> right` corrections. They help WhisperX, fix every new transcript, and guide summaries and Ask. The default LLM can optionally fix misheard terms after transcription, without rephrasing lines.
- **Weekly digest**: one note for a week of meetings (the new Digest button): an overview and themes written by the LLM, plus every decision and action item copied from the summaries, with links to each meeting. It is saved to your Obsidian vault under `digests/`, and can run on a schedule (Settings → Summaries and export).
- **Action items to GitHub issues**: tick action items in a summary and create issues in a repository you choose. Each item then links to its issue, including in the Obsidian note.
- **Use your meetings from Claude and other MCP clients**: `mnemosyne-mcp` exposes list, search, ask, transcript and action-item tools (see the README).
- **Flatpak**: each release now includes a `.flatpak` bundle.

### Fixes
- Asking a question or making a digest could stay on "pending" when the answer came back very quickly.
- The app no longer depends on a tray library being installed; without one it runs without a tray icon.

### Notes
- The Flatpak runs transcription on the CPU (Parakeet) or through a remote transcriber; GPU transcription is not set up inside the sandbox. It updates by installing the next bundle, not through the in-app updater.

### Install
Download the AppImage (`chmod +x`, then run), the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). The backend reinstalls its dependencies once on first launch after upgrading. Verify downloads with `sha256sum -c SHA256SUMS`.
