## Mnemosyne 0.8.0

### New
- **Live copilot**: while you record, a panel keeps running notes of the meeting so far: what was discussed, decided, to do and still open. You can also ask it questions mid-meeting ("what did Ana say about the budget?"). The notes are saved with the meeting, shown on the Summary tab as Live notes, and given to the final summary as a hint; to-dos it heard that the summary missed are added to Tasks, tagged "live". On by default when the live transcript is on (Settings → Recording).
- **Speakers labelled per word**: when the speaker changes in the middle of a sentence, the line is now split there instead of going to whoever spoke most of it. On four recorded test meetings (AMI) this cut wrongly attributed words from about 6% to under 2%.
- **Faster, more accurate speaker identification on NVIDIA GPUs**: with an NVIDIA GPU, speakers are now told apart by NVIDIA's Nemotron model, about ten times faster than before (4 s instead of 43 s for a 38-minute meeting on an RTX 2080 Ti) and with the right speaker for 99.6% of words on the AMI test meetings (98.4% with pyannote). Without an NVIDIA GPU nothing changes: pyannote is used as before. Settings → Transcription → Diarizer: Automatic (the default), Nemotron, pyannote or none. Voice profiles work with both.
- **Summary items link to the transcript**: every decision, action item and open question shows the time it came up; click it to jump to that line.
- **Ctrl+K**: one search box for meetings, people, topics, open tasks, every page and settings tab, and actions like start recording or import. Type "ask" and a question to send it to Ask. There is also a Search button in the header. (Ctrl+K used to open Ask directly; Ask is now one Enter away.)
- **First-run setup**: a short guided setup (audio, transcription, summaries, notes and calendar) on first launch, based on what your machine has. Run it again from Settings.
- **Simpler navigation**: one header with Ask, Tasks, People, Topics and Digest, and Settings split into tabs (General, Recording, Transcription, AI, Notes & sharing).
- **Copy diagnostics** (Settings → General): versions, GPU, engines, recent errors and the end of the log, ready to paste into an issue. Keys, names, addresses and other personal settings are left out; the log part can mention meeting names, so read it before posting publicly. The backend now also keeps a log file (its path is shown there).
- More import formats: .mov, .caf, .3gp, .amr, .aif and .aiff.

### Fixes
- **Recordings interrupted by a crash or a forced restart are recovered**: on the next start the audio is repaired and the meeting finished as if you had pressed stop, with a notice and a Transcribe button. Before, such a meeting stayed "recording" forever.
- **The live transcript slows down instead of slowing your computer down**: when it falls behind or the CPU is busy it transcribes less often, and says so. Nothing is lost; the final transcript covers everything. (Settings → Recording, on by default.)
- Dropdowns in the desktop app were light text on a light background.
- "Transcription complete" could appear several times for one transcription.
- Meetings marked local-only are no longer exposed through the MCP server.
- Search by meaning: fixes for meetings edited while the index was building, and for a model that failed to load once.

### Under the hood
- Every release now starts the real AppImage on a clean system before it is published: it installs its backend, opens a meeting and plays its audio. 0.7.1's white window would have been caught.

### Install
If you run 0.5.0 or later from the AppImage, deb or rpm, the app offers this update itself (deb and rpm installs ask for your password). Otherwise download the AppImage (`chmod +x`, then run), the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). The backend reinstalls its dependencies once on first launch after upgrading; with an NVIDIA GPU the GPU part is reinstalled too (it now includes Nemotron, about 60 more packages), in the background while the app is already usable. Verify downloads with `sha256sum -c SHA256SUMS`.
