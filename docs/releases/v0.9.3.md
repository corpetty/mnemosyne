## Mnemosyne 0.9.3

### Fixes
- **The AppImage has its icon.** File managers, AppImage tools and launchers that read the AppImage's own icon showed none. The link to the icon inside the file pointed to a folder on the machine that built it.
- **The app menu files Mnemosyne under Office.** Its desktop entry had no category, so menus that sort by category left it out or put it under "Other" (AppImage, deb and rpm).

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
