## Mnemosyne 0.6.0

### New
- **Tasks across meetings**: the new Tasks button lists the action items from every summarized meeting, grouped by meeting, filtered by open/done, owner or text. Tick items off there or in a meeting's Summary tab; done items show as `- [x]` in Obsidian notes and the weekly digest.
- **Pre-meeting brief**: when you start a meeting whose title (recurring meetings match across weeks) or attendees match earlier ones, the Recording tab and the calendar banner show what is still open from last time: action items, open questions and the last summary.
- **Follow-up drafts**: "Draft follow-up" in the Summary tab writes an email (with a subject line) or a short chat message recapping decisions and next steps, ready to copy.
- **Chapters**: summaries now split the meeting into chapters with start times. Click one in the Summary tab to jump to it; the transcript shows them as headings and the Obsidian note lists them.
- **Talk time**: a "who spoke when" strip above each transcript (click a turn to jump there) and a talk-time table with each speaker's share, turns, longest turn and pace.
- **Mention alerts**: list words to watch for, usually your name (Settings → Live transcript). When someone else says one while you are recording, you get a desktop notification, a toast and a highlighted line in the live transcript.

### Fixes
- Summarizing a meeting again no longer drops the GitHub issue links on its action items; items that are still there keep their links and done ticks.

### Notes
- Chapters and follow-ups need a summary made with this version; re-summarize older meetings to get chapters.
- Mention alerts need the live transcript to be on.
- The MCP server's meeting and action-item tools now include talk time, chapters and done state.

### Install
If you run 0.5.0 from the AppImage, deb or rpm, the app offers this update itself (deb and rpm installs ask for your password). Otherwise download the AppImage (`chmod +x`, then run), the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). The backend reinstalls its dependencies once on first launch after upgrading. Verify downloads with `sha256sum -c SHA256SUMS`.
