## Mnemosyne 0.27.0

### Mnemosyne's own servers
- **No more testing relays.** Guest notes, remote access, library sync and sharing with contacts now connect through Mnemosyne's own relay, `relay.petty.services`, when two devices can't reach each other directly. n0's free testing relays are no longer a default anywhere.
- **Guest links outlast your computer.** Guest notes are also kept, encrypted, on Mnemosyne's server, `notes.petty.services`, so a link keeps working when your computer is off. The Invite guests menu says so.
- **Publish without running a host.** The publish dialog now offers **Mnemosyne's server** first, next to **This computer** and **A file**. A meeting is encrypted before it leaves your computer, and the key stays in the link.
- **What the servers see.** Encrypted data they can't read, ids, sizes and times, and the IP address of whoever connects. IP addresses aren't written to logs or disk. The [privacy notice](https://notes.petty.services/privacy) has the details.
- **Your choice.** Turn off **Use Mnemosyne's servers** in Settings to use only what you've configured yourself. It starts off on team servers and with cloud models turned off. A relay or host you've set always wins.

### After you update
- **Pair your computers again.** A pairing made before this release remembers n0's relays, so pair each computer again to move it to the new relay, for remote access and for library sync. Computers on the same network keep connecting directly either way.

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
