## Mnemosyne 0.16.0

### Phonon-2 for English meetings
- **A new transcriber for English: Phonon-2** by Fermion Research, a compact version of NVIDIA's Parakeet with its own fast CPU engine. On the AMI meeting recordings (four meetings, 132 minutes) it made fewer errors than Parakeet on every meeting (22.7 % of words against 27.4 %, counting fillers) and ran about four times faster on the CPU, with the same speaker accuracy.
- **Installed when you want it.** Setup now offers Phonon-2 first when your computer's language is English, and Settings → Transcription can install or remove it at any time. Mnemosyne installs it into a folder of its own (about 1 GB, including CPU PyTorch), with every package at a version we tested. Parakeet keeps transcribing until it is ready, and remains the choice for other languages.
- **Automatic picks it for English.** With the transcriber on Automatic (now a choice in Settings) and the language set to English, Phonon-2 is used once installed.
- **Kept to itself.** It runs offline once installed, only on this computer, with a key no other program knows, and it stops when the speech models are unloaded. Long meetings are sent in pieces of five minutes, and silence is skipped.
- You can also point Mnemosyne at your own `phonon` installation.

Phonon-2's weights are CC BY 4.0 (derived from NVIDIA Parakeet TDT 0.6B v3); Fermion's `fermion-research` package is Apache-2.0. Both are downloaded onto your machine when you install it, not shipped with the app.

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
