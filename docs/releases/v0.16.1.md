## Mnemosyne 0.16.1

### Fix
- **Installing Phonon-2 works.** In 0.16.0 the install stopped at its last step: Mnemosyne started Fermion's `phonon serve` with an argument it does not accept, so the model was never downloaded and Phonon-2 could not start (Parakeet kept transcribing). If you tried it, press **Install Phonon-2** again in Settings → Transcription: what was already downloaded is reused, so it finishes quickly.

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
