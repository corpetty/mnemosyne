## Mnemosyne 0.15.0

### Recordings and transcripts that survive crashes
- **A relaunched app picks up its recording again when an API token is set.** If Mnemosyne crashed while recording, the backend goes on recording for 15 minutes so the relaunched app can carry on. With pairing or remote access set up (an API token), the relaunched app could not take it over: after 15 minutes the backend stopped, saved the recording and shut down under the open window. It now takes over as intended.
- **The app notices when its backend is gone, and starts a new one.** The header no longer says "Connected" with a recording clock ticking when nothing answers. It says "Backend not answering", stops showing a recording nobody makes, and the desktop app starts a new backend, which recovers whatever was being recorded. If the backend keeps stopping, the app says so instead of trying forever.
- **Quit works when the backend is gone.** The quit dialog used to say "Load failed" and leave a window that could not close.

### Faster name checking after transcription
- **"Checking names and terms" takes seconds, not minutes.** With a glossary and LLM correction on, the transcript went to your summary model in batches, one at a time, and reasoning models (such as Qwen3) thought before every batch: a 16-minute meeting sat at 99 % for over eight minutes. The check now asks the model not to think first (vLLM, Ollama and the built-in model), sends up to four batches at once and shows its progress ("3 of 12"). On vLLM with Qwen it went from 20-40 s a batch to 1-3 s, with the same corrections.
- **A transcription is never lost in that step.** Stopping or restarting during the check used to throw the finished transcription away; it is now saved.
- **Looking at another meeting during a transcription** no longer makes the running one look untouched when you come back: its progress shows again and the transcript appears when it is done.

### Sharing this computer with your team
- **Keep sharing after quitting** (Settings → General): teammates keep their access, and their browser recordings go on, when you quit the app.
- **Use my Tailscale name**: a real certificate for your machine's tailnet name, so teammates see no browser warning and can join from home over Tailscale.
- Laptops that move between networks: the certificate is renewed for the new addresses without a restart.
- While anything records, and optionally all the time the computer is shared, the computer does not go to sleep.

### First run and everyday use
- **Close to the tray** (Settings → General → Window, when a tray is available): closing the window hides it; recordings and sharing go on.
- **Models ready up front**: setup's last step downloads the speech models with progress, so the first recording starts at once, and a transcription that has to download models says how far along it is.
- **GPU support is a choice** in setup (about 7 GB), and can be installed later from Settings → Transcription.
- **The offline AppImage carries the CPU speech models**, so it installs and transcribes with no network at all. The search model download is half the size (126 MB).

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
