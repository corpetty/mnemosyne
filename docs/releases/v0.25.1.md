## Mnemosyne 0.25.1

### Guest notes on a phone
- **Comments work from a phone.** Select text and tap **Comment** in the bar above the keyboard: a box opens just above the keyboard with the text quoted. Before, the tap lost the selection and nothing happened.
- **Threads open where you are.** Tapping a highlighted comment opens its thread in the same box, to read and reply.
- **Everything fits.** On a narrow screen the page has three tabs: **Notes**, **Agenda** and **Comments** (with the number of open threads). Reply, Edit and Delete are easy to hit with a thumb, and **Show in notes** takes you back to the text.
- **The keyboard no longer covers your typing.** The line you're typing stays above the keyboard. On touch screens the toolbar above the notes is hidden; the bar above the keyboard has bold, italic, lists, tasks, **/** and **Comment**.
- Wider screens and the desktop app are unchanged.

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
