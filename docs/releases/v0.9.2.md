## Mnemosyne 0.9.2

### Fixes
- **A recording survives the app crashing or being closed by force.** The app's backend used to keep running on its own after that, still holding its port. Starting the app again then stopped that recording without saying so and showed Record, not the recording. Now the backend waits for the app: it keeps recording for 15 minutes, and a desktop notification tells you so. Start Mnemosyne in that time and it picks the recording up: Stop, the time and the live transcript so far are all there. If nobody comes back, the recording is stopped and saved as if you had pressed Stop, and the backend shuts down.
- **The backend no longer outlives the app.** When the app is gone and nothing is being recorded, the backend shuts down, after finishing a transcription or summary it was working on.
- **A second backend never touches the first one's recording.** It checks the port before doing anything else and quits if the port is taken. When the app starts, it takes over a backend of its own version that is still running. It replaces an older one, and the recording that backend was making is recovered into its meeting.

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
