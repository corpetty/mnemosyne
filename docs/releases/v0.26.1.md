## Mnemosyne 0.26.1

### Transcribing on computers without an NVIDIA GPU
- **Long monologues no longer stop a transcription.** When one person talked for more than about two minutes without a break, telling speakers apart failed with "Attempting to broadcast an axis" and the meeting stayed untranscribed. Press **Transcribe** again on any meeting this happened to: its audio is still there.

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
