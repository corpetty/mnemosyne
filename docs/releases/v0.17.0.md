## Mnemosyne 0.17.0

### Tasks that are yours
- **Tasks opens on Mine.** Next to it, **Following** holds other people's items you starred (☆) because you are waiting on them, and **Everyone** still shows all of them. The count at the top is what is open for you.
- **"Me" is you.** Items owned by "Me", "I" or "Jonny and Me" count as yours, and naming a speaker ("Speaker 12" → a name) also renames that owner on the meeting's action items.
- **Fewer, sharper action items.** Summaries now know who recorded the meeting, write your name for "I", and list only what someone actually committed to: no decisions restated as tasks, no repeats. The live copilot's to-dos join the summary only when they are yours; the rest stay in its notes.
- The command palette's open tasks list only yours and the ones you follow.

### Obsidian
- **Checkboxes only for your tasks.** Exported meeting notes give checkboxes to your tasks and the ones you follow; everyone else's are plain bullets under "Others", so vault-wide task queries (Tasks, Dataview) list only your work. Person notes list people's open items as bullets, with the ones you follow under "Waiting on". Settings → Obsidian → **Export all meetings again** rewrites the notes you already have; choosing "Everyone's" there keeps the old way.
- **Ticks come back.** Tick a task in an exported meeting note and Mnemosyne marks it done within a few minutes (and before any export, so exporting again never undoes it); the meeting's history says "by Obsidian". Ticking in the app updates that one line of the note, with the Tasks plugin's ✅ date.
- **Links to your own notes.** Words in summaries, decisions, tasks and topics that are the name of a note in your vault become [[links]] (once per section; never dates, common words or Mnemosyne's own notes). Settings → Obsidian can turn it off.
- **Topic notes.** Topics → **Save to Obsidian** writes where a topic stands and every meeting that discussed it to `topics/<Topic>.md`.
- **Decisions log** (optional): one note with every meeting's decisions, newest first.
- **Ask answers to the vault.** **Save to Obsidian** on an answer writes it with links to the meetings it drew on.
- Notes Mnemosyne did not write are never overwritten.

### Phonon-2
- **Used live too.** Live transcription has an Automatic choice (the new default): Phonon-2 for English when it is installed, else Parakeet. Settings show which engine Automatic uses.
- **Use Phonon-2.** If Phonon-2 is installed but your settings still pick Parakeet (or the language is not set), its card says so and switches with one click.
- **Checked end to end.** Every package Phonon-2 installs is pinned by its SHA-256, and the model is verified before each start; a model that does not match is refused and Parakeet transcribes. Each release now installs Phonon-2 for real and transcribes a meeting with it before it is published.
- Fixed: Phonon-2 failed to start about once in 64 starts (its key could begin with "-").

### Install
The app offers this update itself if you run the AppImage, deb or rpm. Otherwise download the AppImage (`chmod +x`, then run), the offline AppImage, the `.deb`, the `.rpm` or the `.flatpak` (`flatpak install --user <file>`). Verify downloads with `sha256sum -c SHA256SUMS`.
